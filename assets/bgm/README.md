通常のBGMは曲全体をループします。別れ、変身、召喚、伝説級・神話級加入、勝利では曲の冒頭を短い演出として再生します。MP3が未登録の場合は既存の合成音で続行します。

GitHubの画面から追加する場合は1ファイル25 MiBまでです。`main` にコミットすると、同ブランチを本番ブランチに設定しているNetlifyサイトのデプロイ対象になります。公開先でも「サウンドテスト」から登録と再生を確認できます。
