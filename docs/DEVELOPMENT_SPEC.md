# 一美のスター街道 開発仕様

## 1. 開発方針

既存ゲームを土台とした大規模なブラウザRPG。スマートフォン横画面の操作性を最優先し、タブレットとPCにも対応する。インストール不要でURLから遊べる。既存機能・セーブを維持し、有料サービスなしで動作させる。絵・音楽・効果音はオリジナルとする。各機能の実装後に動作を検証する。

## 2. 本編と戦闘

一美が愛猫ソソを探す全12章。各章に独自名・戦術を持つ中ボスと章ボスを各1体配置する。独立した四天王4体、隠しボス12体を加える。第10章では、最強の生物ソソが気まぐれでアウレリオに懐いたため連れ去られたと判明し、救出後に加入する。第11・12章は世界滅亡を防ぐ決戦。ソソ同行でも高難度とし、クリア後も探索と生活を続けられる。

フィールド接触で横視点戦闘に移り、一美のみを操作する。仲間は自動戦闘。移動、攻撃・長押し連撃、回避、ジャンプ・二段ジャンプ、空中斬り、指輪によるMP消費魔法を組み合わせ、マルチタッチに対応する。空中斬りは基本130%、魔法は基本35%で原則50%以下。フィールドでもジャンプ・攻撃・魔法が使え、壺や障害物を壊せる。種別ごとにモーション・効果音・エフェクトを用意し、武器の重量とレベルで速度や残像が変わる。

## 3. ソソと超覚醒

新仕様の形態とターンは無属性0、炎3、水・氷5、雷7、闇10、全属性15。最終形態は全能力最大。変身中に被弾すると第一形態へ戻って進捗を失う。普段は一美の足元や後方にいて、変身後は自動戦闘する。第5・6形態は遠距離攻撃が可能。一美のHP低下時はソソが守りに入り、ソソのHPが10%以下になると一美が黄金の超覚醒を発動する。超覚醒で通常敵を一掃できるがボスには攻略が必要。HPは独立し、どちらかの死亡で悲しい演出付きゲームオーバー。勝利後はソソが甘える。特殊能力「ソソを思う」は15秒クールタイム。

## 4. 装備と強化

装備は武器200、防具200、靴200、盾100、魔法の指輪2,000の計2,700種類。

- 武器内訳は棒・棍棒20、短剣20、片手剣30、両手剣25、刀20、斧15、槍15、ハンマー15、鎌10、双剣15、特殊15。入手内訳は店80、敵ドロップ40、宝箱30、製作25、クエスト15、隠しボス10。重量、適正レベル、速度、射程、最大Lv99の熟練度、固有モーションを持つ。木の棒は0.2kg、攻撃力3、攻撃間隔0.25秒。
- 防具はオリジナルブランド。重量で移動、ジャンプ、回避が変化し、レベルで克服する。靴は外見・足音・性能を持ち、水上・溶岩歩行、壁蹴り、三段ジャンプ、空中ダッシュ、踏みつけを実装する。盾は重量・物理防御補正なしで魔法ビームを最大99%で反射し、敵にも命中する。
- 強化は全品＋99まで成功率100%、消失なし。魔石は敵直接ドロップ限定。小＋1〜10・40%、中＋11〜20・20%、大＋21〜30・10%、上級＋31〜50・5%、至高＋51〜70・2%、伝説＋71〜90・0.5%、神＋91〜99・0.05%。＋10、30、50、70、90、99で発光が変化する。
- 指輪は各100種の20系統。炎、氷、雷、風、爆発、水、土、光、闇、重力、回復、蘇生、治療、強化、結界、弱体化、状態異常、吸収、時空、探索。一美とソソの死亡は蘇生不可。
- 通常ガチャは100G。種類数／確率はノーマル800／50%、アンコモン500／25%、レア350／15%、スーパーレア200／7%、エピック100／2.5%、レジェンド40／0.45%、神話級10／0.05%。隠しルートの特別ガチャも100G、伝説級以上を90%／9%／1%の表で抽選する。現実のお金は使わない。

## 5. モンスターと仲間

基本500種に無・炎・水・氷・雷・風・土・毒・光・闇・時・聖を組み合わせ通常6,000種、ボス込み6,040種。属性は外見・体格・攻撃・魔法・行動・生息地・鳴き声・ドロップに作用する。強さは1・2・3・5・10・20倍で、プレイヤーLvへの無条件追従なし。性格14種は普通、攻撃的、慎重、知的、臆病、好奇心旺盛、変わり者、温厚、無関心、眠たがり、狂暴、模倣型、人懐っこい、謎めいた。非反撃、踊り、バク転、天井張り付き、模倣、ソソと遊ぶ行動を設ける。

契約石は第3・6・9章の隠しダンジョンに赤・青・金を各1個。各石は1体に対応し、解放後に再利用可能。残HP100/75/50/25/10/1%で基本捕獲率1/5/15/30/60/90%、強さと性格で補正する。王クラスの通常敵も捕獲可能。能力・属性・性格を継承し、改名、レベル、好感度、連携、必殺技を持つ。

仲間候補は100人。剣士10、盾役10、武闘家8、魔法使い12、僧侶8、賢者6、盗賊8、弓使い8、忍者6、商人5、鍛冶師5、魔物使い5、吟遊詩人4、特殊職5。固有の名前・外見・性格・過去・人生観、30能力、最大Lv99、必殺技5、スキル20、成長率、装備、個別物語と好感度を持つ。人間・特殊仲間の同行枠は1、酒場で無料交代し離脱後も成長と装備は保持。最大編成は一美、人間枠1、ソソ、捕獲3の6体。作戦は攻撃、バランス、回復、MP節約、防御、変身支援。主要仲間は物理の一郎、回復の恵美ちゃん、自然のタク、飛行探索のクルミ、第4章クエストの盾役バルド。バルドは挑発、かばう、10秒間90%軽減、魔法反射、ノックバック無効、致死耐久1回、周囲被ダメ50%減、スタミナ制限。

宿は24時間営業で、宿泊、食事、入浴、露天風呂、サウナ、起床時刻、疲労回復を扱う。恋愛は成人同士の相性と合意を条件とし、食事、星空、手つなぎ、抱擁、キス、告白、ロマンチックな夜と翌朝の会話を用意する。女性仲間との遠足・女子旅にはお菓子、会話、入浴、買い物、髪型、枕投げを用意する。相性が悪い仲間との口論は選択で仲直り、悪化、離脱に分岐。喧嘩別れは置き手紙、手持ち全額喪失、好感度−100。預金と酒場交代は対象外。後日再会、謝罪、和解、返金、再加入、再裏切りが性格で分岐する。
