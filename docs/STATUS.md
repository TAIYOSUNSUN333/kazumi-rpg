# 開発進捗と再開手順

全体の目標は [開発仕様](DEVELOPMENT_SPEC.md) を参照。チェック済みの範囲を明記する。ロードマップの数量は目標値。

## 調査結果

- 配信は静的HTML/CSS/JavaScript。外部ビルドや依存パッケージなし。index.html がUI、world.js が章・敵・装備データ、game.js が入力・進行・保存、render.js がCanvas描画、audio.js がオリジナル合成音。netlify.toml が静的公開先を指定。
- 既存の全12章、中ボス12体、章ボス12体、四天王4体、ソソ加入、フィールド接触、横視点戦闘、レベル、装備購入、旧覚醒、オリジナルBGM、帰宅エンディングを確認。通常敵は少数の行動タイプを章ごとに配置している。
- localStorage の kazumi が冒険、kazumi-audio が音量設定。着手時の最新はv4。v2・v3からの移行があり、さらに古いセーブは読める範囲の経験値等を引き継ぐ。今回のv5は指輪と壺状態を追加し、v4の仲間・敵撃破・試練報酬等を維持する。ジャンプ、戦闘中の覚醒タイマーは再開時に初期化する。
